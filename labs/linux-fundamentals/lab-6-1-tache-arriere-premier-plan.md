# Lab 06 — Taches d'arriere plan et de premier plan

## Objectif

lancer un programme graphique a partir du terminal puis s'exercer a le deplacer entre le premier plan et l'arriere plan(ubuntu default calculator app)

## commandes executess

## sudo apt install gnome-calculator
pour installer le calculator

## gnome-calculator
pour lancer la calculatrice

## Ctrl + Z
pour stopper le job(la calculatrice ne va plus repondre malgre le fait qu'elle soit toujours ouverte)

## jobs -l
lister les app(jobs) ouvert depuis ce terminal

## bg
pour reprendre le travail sur la calculatrice  mais toujours en arriere plan

## fg
pour faire revenir le job(calculatrice) au premier plan

## Ctrl + Z
pour stopper le job(calculatrice)

## kill -9 gid
pour supprimere le job
